# Remote Warfare

> 远程战争 · 战棋指挥网页小游戏（开发中）

**在线地址**：https://ku-134.github.io/Kukuz-Game-Remote-Warfare/

**当前版本**：0.2.0（开发中）

## 简介

一款强调「面对失控战局进行指挥」的战棋网页小游戏。核心流程：指挥单位（操作）-> 结算（行动判定）-> 单位完成指令（返回结果）。采用线性闯关，前几关为教学。

## 功能列表

- 启动序列：老电脑自检 -> 终端模块装载 -> 运行校验 -> CRT 点亮过渡
- 开始界面：开始作战 / 显示设置 / 关于本系统
- 显示设置：磷光强度、扫描线、辉光、亮度，即时生效并持久化
- 磷光屏美术引擎：扫描线、光晕、信号故障、噪点、暗角、闪烁、CRT 开机动画
- 军用方格网格 + 等高线地形层 + 河流湖泊渲染
- 单位系统（人数 / 物资 / Buff 三类变量）
- 零美术资源：全部视觉由程序生成，无外部图片依赖

## 操作说明

- 启动序列：按任意键 / 点击可跳过。
- 开始界面：`↑↓/WS` 选择，`ENTER` 确认；触屏可直接点击。
- 显示设置：`←→/AD` 调整，`ESC` 返回。
- 游玩界面：点击方格选择单位，`ESC` 返回主菜单。

## 技术约定

- 纯静态：HTML + CSS + JavaScript，零构建、零依赖，Canvas 2D 渲染。
- 全局命名空间 `RW`，多文件按序加载。
- GitHub Pages 托管，push `main` 即发布。
