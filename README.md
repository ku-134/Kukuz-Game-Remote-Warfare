# Remote Warfare

> 远程战争 · 战棋指挥网页小游戏（开发中）

**在线地址**：https://ku-134.github.io/Kukuz-Game-Remote-Warfare/

**当前版本**：0.4.0（开发中）

## 简介

一款强调「面对失控战局进行指挥」的战棋网页小游戏。核心流程：指挥单位（操作）-> 结算（行动判定）-> 单位完成指令（返回结果）。采用线性闯关，前几关为教学。

## 功能列表

- 启动序列：老电脑自检 -> 终端模块装载 -> 运行校验 -> CRT 点亮过渡（可跳过）
- 开始界面：开始作战 / 设置 / 关于本系统
- 设置层级：
  - 显示设置（12 项）：磷光强度、扫描线、辉光、磷光余晖、亮度、屏幕曲率、色彩偏移、噪点、荧光闪烁、滚动亮带、暗角、刷新速度
  - 即时生效、自动保存、可恢复默认
  - 音频 / 操作入口（预留）
- 游玩界面四区布局：地图显示 / 地图操作 / 单位下令区 / 详情展示
- 界面过渡：扫描擦除 + 文字分步揭示
- 像素字体：内置 5x7 点阵字库，标题与菜单均为像素风格
- 交互反馈：按钮点击先闪三下
- 信号干扰（剧情演出）：战场信号被屏蔽时覆盖地图并锁定操作
- 磷光屏美术引擎：曲面畸变、扫描线、光晕、色散、噪点、暗角、滚动亮带、闪烁、余晖、CRT 开机动画
- 地形：等高线 + 河流湖泊 + 七级色阶
- 零美术资源：全部视觉由程序生成

## 操作说明

- 启动序列：按任意键 / 点击跳过。
- 主菜单：`↑↓/WS` 选择，`ENTER` 确认；触屏可直接点击。
- 设置：`ENTER` 进入子项；显示设置内 `↑↓` 选项、`←→` 调值、`ESC` 返回。
- 游玩界面：点击方格选择单位（右侧详情栏联动），`ESC` 返回主菜单。

## 技术约定

- 纯静态：HTML + CSS + JavaScript，零构建、零依赖，Canvas 2D 渲染。
- 全局命名空间 `RW`，多文件按序加载。
- GitHub Pages 托管，push `main` 即发布。

- 运行：直接双击打开 `index.html` 即可（无构建）。
