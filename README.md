# Remote Warfare

> 远程战争 · 战棋指挥网页小游戏（开发中）

**在线地址**：https://ku-134.github.io/Kukuz-Game-Remote-Warfare/

**当前版本**：0.5.0（开发中）

## 简介

一款强调「面对失控战局进行指挥」的战棋网页小游戏。核心流程：指挥单位（操作）-> 结算（行动判定）-> 单位完成指令（返回结果）。采用线性闯关，前几关为教学。

## 界面流程

启动序列 -> 开始界面 -> 关卡简报 -> 游玩界面

- **启动序列**：老电脑自检 -> 终端模块装载 -> 运行校验 -> CRT 点亮（可跳过）
  - 缓存机制：版本号与模块清单未变化时，只播一次短过渡直达开始界面
- **开始界面**：开始作战 / 设置 / 关于本系统
- **关卡简报**：关卡代号、名称、任务目标与说明逐行播报，播报完成后进入关卡
- **游玩界面**：地图显示 / 地图操作 / 操作区 / 详情展示

## 游玩界面说明

| 区域 | 占比 | 功能 |
|---|---|---|
| 地图显示 | 左 2/3 | 局部视口，坐标/缩放/比例尺仪表，点击选中单位或地块 |
| 地图操作 | 左下窄栏 | 放大 / 缩小 / 上移 / 下移 / 左移 / 右移 |
| 操作区 | 左下宽栏 | 选中单位 -> 指令；选中地块 -> 标记位置 |
| 详情展示 | 右 1/3 | 单位状态（人数/物资/战力/机动/Buff）或地块情报 |

## 功能列表

- 磷光屏美术引擎：曲面畸变、扫描线、光晕、色散、噪点、暗角、滚动亮带、闪烁、余晖、CRT 开机动画
- 显示设置 12 项（即时生效、自动保存、可恢复默认）
- 像素字体：内置 5x7 点阵字库
- 交互反馈：按钮点击先闪三下；切屏为扫描擦除 + 文字分步揭示
- 信号干扰（剧情演出）：战场信号被屏蔽时覆盖地图并锁定操作
- 地形：等高线 + 河流湖泊 + 七级色阶
- 零美术资源：全部视觉由程序生成

## 操作说明

- 启动序列：按任意键 / 点击跳过。
- 主菜单：`↑↓/WS` 选择，`ENTER` 确认；触屏可直接点击。
- 关卡简报：播报完成后按任意键进入。
- 游玩界面：点击地图选择单位/地块，右侧详情联动；地图操作区缩放与平移；`ESC` 返回主菜单。
- 设置：`ENTER` 进入子项；显示设置内 `↑↓` 选项、`←→` 调值、`ESC` 返回。

## 技术约定

- 纯静态：HTML + CSS + JavaScript，零构建、零依赖，Canvas 2D 渲染。
- 全局命名空间 `RW`，多文件按序加载。
- GitHub Pages 托管，push `main` 即发布。
